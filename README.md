# Zoo Website – Webbutveckling 1

This project is my first and was created as an assignment in the course **Webbutveckling 1**.
The task was to build a responsive website for a fictional zoo using HTML and CSS.

## 📄 About the project
The website presents a fictional zoo with information about animals, layout sections and basic navigation.
The focus of the assignment was correct HTML structure, semantic elements, and responsive layout using CSS.

## 🛠 Technologies used
- HTML5
- CSS3
- JavaSscript
